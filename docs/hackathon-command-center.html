Stage Three (bonus points):

  • +0.2 max — publish a public (not unlisted) blog/podcast/video content piece; it must state it was created "for the purposes of entering this hackathon".

Final score runs "from 1 to 6, with the highest possible Final score being 6." Tiebreak: "Ties will be broken by comparing scores on each criterion in the order listed, and if a tie remains, judges will vote."
